## Trust and completed fixes

Readback authenticates it, verifies the current campaign/source/runtime/scope and whole-candidate key, reconstructs complete topology and rehashes all referenced artifacts. A file containing a success word or an arbitrary SQLite completion cannot mint this authority.

The HMAC authenticates a trusted local coordinator execution. It neither proves the interval kernel in Lean nor transfers trust to a third party. A concrete resource-policy defect was found and fixed: the native callback originally accepted return code zero without checking the supervisor's termination reason. The runner now requires `reason == completed`, zero exit and `tree_cleanup_complete == true`. A zero exit can coexist with a detected time/log limit race; it must not override that limit. The two negative policy tests establish the fixed boundary.
