## 3. beta1's new physical-theta mean floor, including atoms

The distinct rule is `mean_floor.py:5--15`. Let
`p=P(X>0)`, `q=1-p`, `m=E X_+=E(-X)_+`. Assign a zero atom to the nonpositive
class. For a nondegenerate centered variance-one law, p,q>0 and conditional
class means are `m/p` and `-m/q`. The law of total variance gives exactly

```
1 = theta + m^2/[p*(1-p)],
theta = q*Var(X|X<=0) + p*Var(X|X>0).
```

Thus if acquired physical theta<=t<=1 and p in `[l,u]`, then

```
m >= sqrt((1-t)*min(l*(1-l),u*(1-u))).
```

The minimum is at an endpoint because p(1-p) is concave; crossing1/2 changes
the maximum, not this minimum. A zero endpoint yields a weaker zero floor,
not a division by zero. The actual helper checks exact Fraction types,
ordered p/t bounds and a positive integer grid, then returns
`isqrt(floor(x*G^2))/G`, G=10^12. Its square is <=x, hence it is a downward
root. Taking its maximum with valid earlier mean floors preserves the lower
direction. These statements require no sample-index transfer.

`mixed_beta1.py:62--65` passes **raw_row.theta**, the actual normalized
within-sign variance upper bound. It does not pass `theta_weighted`, a lambda
