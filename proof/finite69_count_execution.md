## Completed-stage cache and failure export

Each completed forest is fully revalidated before ZIP export with an actual
SHA-256 sidecar. A later RunAll restores only safe bounded ZIPs, verifies the
sidecar and every source/capture/receipt again, and skips native computation only
after successful whole-stage validation. Invalid/incomplete caches are rejected;
the native stage then starts fresh. Partial numerical stages are never resumed
