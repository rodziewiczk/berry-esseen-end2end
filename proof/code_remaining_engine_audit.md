There is a substantive new inequality at72–106 and172–203; it is not justified
merely by the word “weighted.” For a centered residual `U in [l,r]`, variance
`w`, and `l<0<r`, the nonnegative quadratic products give

`l*w - w^2/l <= E[U^3] <= r*w - w^2/r`.

For example, expanding `E[(U-t)^2*(r-U)]>=0` and choosing `t=-w/r` proves
the upper inequality. Also

`E[U^4] <= (l+r)*E[U^3] - l*r*w`,

by `E[(U-l)*(r-U)*U^2]>=0`. In the strict-outgoing quartic its relevant
moment expression is `-E[U^4]+4*u*E[U^3]`. Put `c=l+r-4*u`. If `c>=0`,
use the upper cubic endpoint `x=r`; if `c<=0`, use the lower endpoint `x=l`.
Both cases yield the lower bound

`-x^2*w + 4*u*x*w + (l+r-4*u)*w^2/x`.

The source's `r0=(n-k)*w0^2/x0` and `r1=k*w1^2/x1` therefore add exactly
`(a0-O0)*r0+(O1-a1)*r1` to the constant coefficient and
`-4*(r0+r1)` to the phase coefficient. Negative endpoint divisors are handled
by signed scalar interval arithmetic; they are not passed as a forbidden
positive interval divisor. At a zero endpoint the centered supported law
has zero variance, explicitly required before using the continuous zero
value. A positive interval variance upper endpoint can conservatively make
this optional rule unavailable; it cannot license a false zero substitution.

Independent centered residuals give
`E[W^4]=sum E[U_i^4]+3*(V^2-sum w_i^2)` and
`E[W^3]=sum E[U_i^3]`; this supplies precisely the source's remaining
`3*J`, concave variance and phase coefficients. Closed endpoint switch
handling is as in section7. In172–203, maximizing the whole coefficient/case
bound before minimizing complete quartic strategies is again necessary and
