## Specific paper/source discrepancies

1. Retain the explicit nonnegative own-binomial mass premise from
   [R1](logic_audit_repairs.md); the representative exact source enforces it.
2. The resource implementation enables a piecewise signed Pearson rectangle
   broader than the specialized M<3/R>2g rectangle displayed in the paper.
   Its source-review derivation needs an explicit place in the revised
   paper. Removing the older gate without that extension would be invalid.
3. The selected HIGH comparator uses sqrt(M-1), without the optional1.85
   minimum described in the manuscript. This is a weaker valid bound; the
   revised implementation description must name the actual expression.
4. An unused current7 quarter-provenance constant names the older v11
   preparer. The selected V12 source/contract bindings independently use the
   correct bytes. The exact corrected identity is recorded in the join audit;
   the running implementation is preserved rather than silently rebound.
5. The actual n25 support callback uses a direct-Gaussian full-ray argument
   valid from n>=2. The manuscript's displayed n>=36 polynomial support
   recipe is a different method. The revised paper needs the direct-support
   lemma and its actual same-law hypotheses; see [R6](logic_audit_repairs.md).
6. A selected old36–39 contract omitted the phase factor
   `15000/(997*n)` in its prose. Its original join already requires the
   separately named corrected scope. A future replay/join must retain
   that correction; see [R7](logic_audit_repairs.md).
