## 1. One physical deficit licenses both exported intercepts

Use the manuscript's physical defect
`D=(3+sqrt(10))*rho-gamma-3J`, not a separately normalized or newly optimized
defect. Let `theta` be the conditional variance after conditioning on sign,
`m^2=(1-theta)*p*(1-p)`, and let `DeltaA,DeltaB>=0` be the inward endpoint
displacements from the conditional binary means. The same-law positive
measure identity at manuscript2477–2533 gives

```
D >= b + 6*m*S_*(DeltaA+DeltaB) + K*theta,
b >= 0, S_* <= A+B, K > 0.
```

The dropped additional displacement product and the two separately priced
variance terms are nonnegative. In the actual panel calculation,
`b` is a lower bound on
`(6+2*sqrt(10))*(1-theta)^(3/2)*(p-p_*)^2/sqrt(p*(1-p))`,
where `p_*=(4-sqrt(10))/2`. The variance price is the smaller of
`3*(sqrt(10)+1)*B_lower` and `3*(sqrt(10)+3)*A_lower`.

Suppose the *same law*, at actual index `n>=N`, has the weighted input
`n*D<=N*d_saved`, `theta<=Theta<1`, `p*(1-p)<=v_*`, and the preceding
simultaneous inequality. Put

```
r = d_saved-b,
d_* = r/[6*(1-Theta)*S_*],
Lambda = N*v_* r/[K*(1-Theta)].
```

For its transformed variable `Y=B0+U`, write
`d_Y=(DeltaA+DeltaB)/(barA+barB)` and `lambda=n*E(U^2)`.
The identities `m*(barA+barB)=1-theta` and
`lambda=n*p*(1-p)*theta/(1-theta)` give

```
N*d_saved >= n*D

          + K*(1-Theta)*lambda/v_*.
```

For `r>0`, division yields the single physical statement
`d_Y/d_*+lambda/Lambda<=1`. This is manuscript2591–2629, including the
important weighted `n*D` input. With `r<0` no such law exists; with `r=0`
both nonnegative resources vanish. The selected comparison inputs have
strictly positive intercepts, so the last boundary is not divided by there.
