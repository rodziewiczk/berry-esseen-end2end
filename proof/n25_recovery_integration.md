# Original n25 recovery: implemented source / replay subsection for delivery66

This change replaces the **preferred ordinary B5 source route**, not the full
nine-section notebook66. No original mathematical acceptor was executed during
this delivery. A source/geometry test is not a numerical acceptance.

## Inputs and immutable identities

The separate asset `assets/BE_cutoff25_missing_files_20261024.zip` is pinned to
SHA256 `3aac9416c286f14465037629f2aa692f1b3f5d2f216ad48821fbb581cc3c70f6`.
`n25_recovery_source_plan.json` binds the original source closures, eleven
candidate forests, historical receipts, mixed-parent sources and regional
references. Its SHA256 is checked in `be_replay/n25_recovery_sources.py`.
The manifest in the archive is not the only trust anchor: the archive and plan
are externally pinned, and plan generation compares the ordinary selected pins
against the earlier `n25_retained_b5_upper_catalog.json`.

The runtime verifies all1836 payload members, rejects unsafe/duplicate/linked
ZIP members, and rechecks each selected member while copying it. Neither source
preparation nor the evidence readers import mathematical code from the archive.
All copied source bytes and the forest headers remain unchanged.

## Ordinary B5 execution

Eleven jobs: V14p26--32 and the four V12p33 quarters. They have32093 leaves;
the largest original tree has8970 nodes. The original `LIMIT=10000`, depth128,
26 closed roots, strict numerical target and all24 corruption controls remain
unchanged. The recovered lane never invokes PREFIX2, construction or discovery.
A failed native replay stays incomplete; it does not silently trigger search or
modify a checker, a limit, a forest header or the recorded leaf arithmetic.

`be_replay.n25_full_counts.prepare(task, target, recovery_archive=...)` selects
this lane. With no legacy capsule argument it also prefers the bundled original
asset. Passing the old explicit `source_capsule` continues to select the frozen
legacy reconstructed lane. Those source plans and kernels are not rewritten.
`run_target(...)` dispatches recovered tasks to `n25_recovered_counts`; ambiguous
original/reconstructed markers fail closed.

The old names `b5-p26-v14-new` throughp32 and the p33 `-reconstructed` names are
accepted only as API lookup aliases; the returned original target identity and
cache namespace are explicitly different. No old accepted receipt is relabelled.

A fresh exclusive execution directory receives the exact original closure and
candidate. The historical `COUNTxx_ACCEPTED.json` is kept under `provenance/`,
not copied into the execution capsule. Only the supervised command
`python -B -S count_protocol.py accept` can produce a fresh result.
The existing Linux single-process native guard and explicit2GiB / at-most82800s

return code or a historical PASS field.

The new pure evidence reader checks the complete unchanged source/candidate,
closed geometry, all leaves, exact statistics, all24 ordered controls, literal
scope, complete stdout and stderr, actual launch, resource guards and current
implementation bindings. Relocation preserves the original recorded paths and
receipt bytes. This is evidence readback, not an independent second numerical
implementation of the original leaf inequalities.

Complete stages are exported immediately with SHA256 sidecars into a namespace
separate from old reconstructed counts and01--07. Reuse performs the full reader;
partial stages and malformed cache ZIPs are not accepted. A locally completed
stage whose Drive export failed can be revalidated and exported without rerunning
its mathematics. Live logs are backed up every60s and the existing supervisor
prints20s heartbeats. Failure of the final durable bundle is propagated.

## Mixed parents and regional references

`prepare_all` stages both exact original V14p24/p25 parent closures, plus the
producer-gate files and the four regional files (two selectors and two join
records). These are source/provenance only. The mixed forests/acceptors from the
original base archives, E/ABCDF and scalar registries, fresh acquisitions and
current same-law joins remain required. An ordinary replay is not a mixed proof.
Original identities eliminate the replacement contracts that were needed solely
because bytes were missing; they do not eliminate current parent acquisition.

The B3 selector identifies the exact V12p34 route. Historical regional PASS
records are not a substitute for a new20-piece physical union. Recovery of old
B3/B4 forests does not invalidate completed notebooks01--07 or require reruns.
